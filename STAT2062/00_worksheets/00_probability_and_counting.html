A

Sample spaces and events

≈30 min · translation drill

Everything later in the unit rests on being able to move between an English sentence and a set expression without thinking about it. Do these fast and often rather than slowly and once.

A1

Write the sample space for each experiment, then classify it as finite, countably infinite, or uncountably infinite.

  1. Roll two distinguishable dice and record the pair.
  2. Toss a coin until the first head appears; record how many tosses it took.
  3. Measure the time in seconds until a radioactive particle decays.
  4. Draw one card from a standard 52-card deck.
Solution
  1. S = {(i, j) : i, j ∈ {1, …, 6}}, so |S| = 36. Finite.
  2. S = {1, 2, 3, …}. Countably infinite. If you want to allow "no head ever", append that outcome — the space is still countable.
  3. S = [0, ∞). Uncountably infinite, i.e. continuous.
  4. 52 outcomes. Finite.

Countable = finite or countably infinite. Discrete and continuous are the two labels the unit will keep using.

A2

A coin is flipped 6 times. Let Aj be the event that flip j is heads. Write each event using Aj, unions, intersections and complements.

  1. The first three flips are heads and the last three are tails.
  2. At least one of the last two flips is a tail.
  3. No two consecutive flips are heads.
  4. Rewrite (A1 ∪ A2 ∪ A3)c using intersections, and say in English what it means.
Solution
  1. A1 ∩ A2 ∩ A3 ∩ A4c ∩ A5c ∩ A6c
  2. A5c ∪ A6c, which by De Morgan is (A5 ∩ A6)c — "not both heads".
  3. "Two consecutive heads somewhere" is D = ∪j=15 (Aj ∩ Aj+1), so the answer is Dc = ∩j=15 (Ajc ∪ Aj+1c).
  4. A1c ∩ A2c ∩ A3c — none of the first three flips is heads.

Pattern worth memorising: "at least one" is a union, "all" is an intersection, and De Morgan swaps the two whenever you complement.

A3

Let A, B, C be events in a sample space S. Write each in set notation.

  1. Exactly one of A, B occurs.
  2. At least two of A, B, C occur.
  3. None of the three occurs.
  4. Exactly two of the three occur.
  5. A occurs but neither B nor C does.
Solution
  1. (A ∩ Bc) ∪ (Ac ∩ B)
  2. (A ∩ B) ∪ (A ∩ C) ∪ (B ∩ C) — note these overlap, which is fine for describing the event, though it matters when you compute its probability.
  3. Ac ∩ Bc ∩ Cc = (A ∪ B ∪ C)c
  4. (A ∩ B ∩ Cc) ∪ (A ∩ Bc ∩ C) ∪ (Ac ∩ B ∩ C) — these three are disjoint.
  5. A ∩ Bc ∩ Cc
A4

True or false? Justify each, with a counterexample where the claim fails.

  1. If A ⊆ B, then A and B cannot be mutually exclusive.
  2. There exist mutually exclusive events with P(A) = 0.6 and P(B) = 0.5.
  3. If A1, …, An partition S, then they are pairwise disjoint and their union is S.
  4. A ∪ B = S implies A and B are complements.
Solution
  1. False. If A ⊆ B then A ∩ B = A, so they are mutually exclusive exactly when A = ∅. Counterexample: A = ∅, B = S.
  2. False. Disjointness would force P(A ∪ B) = 1.1 > 1, violating the first axiom.
  3. True — that is the definition.
  4. False. Complements also require A ∩ B = ∅. Counterexample: A = B = S.
B

Counting foundations

≈35 min · mechanical, then applied

Multiplication rule, sampling with and without replacement, permutations. Before each answer, say out loud whether order matters and whether replacement is allowed — most errors here are choosing the wrong one of the four combinations.

B1

A lab passcode is 5 characters long, each drawn from the 26 lowercase letters plus the 10 digits (36 characters in total).

  1. How many passcodes are there?
  2. How many have no repeated character?
  3. How many contain at least one digit?
  4. If a passcode is chosen uniformly at random, what is the probability all five characters are distinct?
Solution
  1. Sampling with replacement, order matters: 365 = 60,466,176.
  2. Without replacement: 36 · 35 · 34 · 33 · 32 = 45,239,040.
  3. Complement is easier: total minus letters-only, 365 − 265 = 60,466,176 − 11,881,376 = 48,584,800.
  4. 45,239,040 / 60,466,176 ≈ 0.7482.

Whenever the phrase "at least one" appears, check the complement first. It is nearly always fewer cases.

B2

A set has 10 elements.

  1. How many subsets does it have?
  2. How many subsets of size exactly 4?
  3. How many subsets have an even number of elements?
  4. Justify (c) using the binomial theorem with a well-chosen x and y.
Solution
  1. 210 = 1024 — each element is independently in or out.
  2. C(10, 4) = 210.
  3. 29 = 512.
  4. Put x = −1, y = 1 in (x + y)n = Σk C(n, k) xk yn−k. The left side is 0n = 0 for n ≥ 1, so Σk (−1)k C(n, k) = 0: the even-sized subsets and the odd-sized subsets are equal in number. Since together they total 2n, each group has 2n−1.
B3

Ten people line up in a random order, all orderings equally likely. Call two of them X and Y.

  1. How many orderings are there?
  2. How many have X and Y adjacent?
  3. What is the probability that X and Y are adjacent?
  4. What is the probability X stands somewhere ahead of Y? Answer this one without counting.
Solution
  1. 10! = 3,628,800.
  2. Glue X and Y into a single block: 9 objects to arrange, and 2 internal orders. 9! · 2 = 725,760.
  3. 725,760 / 3,628,800 = 0.2, i.e. 2/10.
  4. 1/2, by symmetry — swapping X and Y is a bijection between the two cases, so they are equally likely.

(d) is the first appearance of a habit worth building: a symmetry argument replaces a whole counting computation.

B4

A tutorial has 25 students. Assume 365 equally likely birthdays and no twins.

  1. Write an expression for the probability that at least two students share a birthday.
  2. Without computing it, is that probability above or below 0.5? Why?
  3. Now compute the probability that at least one of the other 24 students shares your birthday.
  4. (c) is far smaller than (a). Explain the gap in one sentence.
Solution
  1. 1 − (365 · 364 · ⋯ · 341) / 36525. The numerator samples 25 of the 365 days without replacement.
  2. Above. The lecture's plot crosses 0.5 at k = 23, and the probability is increasing in k. (It is about 0.569.)
  3. 1 − (364/365)24 ≈ 0.064.
  4. (a) has C(25, 2) = 300 pairs that could match; (c) has only the 24 pairs involving you.

This is the standard exam trap for this topic: "someone shares with someone" and "someone shares with me" are different events, and the first grows quadratically in group size.

C

Binomial coefficients and overcounting

≈40 min · the workhorse

Use the form C(n, k) = n(n−1)⋯(n−k+1) / k! rather than the factorial form when computing by hand. It is faster and it will not overflow on you in an exam.

C1

Evaluate by hand, without computing any factorial larger than 6!.

  1. C(50, 2)
  2. C(12, 3)
  3. C(100, 98)
  4. C(9, 0) + C(9, 9)
  5. C(7, 10)
Solution
  1. 50 · 49 / 2 = 1225
  2. 12 · 11 · 10 / 6 = 220
  3. Flip it: C(100, 98) = C(100, 2) = 100 · 99 / 2 = 4950
  4. 1 + 1 = 2
  5. 0, since k > n. This is a definition, not something the factorial formula gives you — factorials of negative numbers are undefined.
C2

A 5-card hand is dealt from a well-shuffled standard deck. There are C(52, 5) = 2,598,960 equally likely hands.

  1. Find the probability of exactly two pairs (two of one rank, two of another, and a fifth card of a third rank).
  2. Find the probability of three of a kind (three of one rank, and two cards of two other distinct ranks).
  3. The lecture found P(full house) ≈ 0.00144. Rank your three answers and explain the ordering in words.
Solution
  1. Choose the two paired ranks together, C(13, 2) = 78, since their order does not matter; choose suits, C(4, 2)2 = 36; choose the odd rank, 11 ways, and its suit, 4 ways. Total 78 · 36 · 44 = 123,552, so P ≈ 0.0475.
  2. 13 · C(4, 3) · C(12, 2) · 4 · 4 = 13 · 4 · 66 · 16 = 54,912, so P ≈ 0.0211.
  3. Two pair (0.0475) > three of a kind (0.0211) > full house (0.00144). A full house demands both patterns at once, so it is rarest; among the other two, three matching cards is a stronger constraint than two plus two.

In (a), using 13 · 12 for the pair ranks instead of C(13, 2) double-counts every hand. In (b), forgetting that the two loose cards must be different ranks silently counts full houses.

C3

A club has 12 members: 7 women and 5 men.

  1. How many committees of 4 are there?
  2. How many contain exactly 2 women?
  3. If the committee is chosen uniformly at random, what is the probability it has exactly 2 women?
  4. How many committees of 4 with a designated chair are there? Compute it two different ways and check they agree.
Solution
  1. C(12, 4) = 495
  2. C(7, 2) · C(5, 2) = 21 · 10 = 210
  3. 210 / 495 = 14/33 ≈ 0.424
  4. Committee then chair: C(12, 4) · 4 = 1980. Chair then the rest: 12 · C(11, 3) = 12 · 165 = 1980. Agreed — and this is exactly the team-captain identity k · C(n, k) = n · C(n−1, k−1) with n = 12, k = 4.
C4
  1. Expand (2x − 3)4 using the binomial theorem.
  2. Find the coefficient of x3 in (1 + x)10.
  3. Find the coefficient of x2y5 in (3x + y)7.
Solution
  1. 16x4 − 96x3 + 216x2 − 216x + 81. Check by squaring (4x2 − 12x + 9) if you want independent verification.
  2. C(10, 3) = 120.
  3. C(7, 2) · 32 = 21 · 9 = 189. The coefficient inside the bracket gets raised to the power too — the most common slip here.
D

Story proofs

≈40 min · do this set first, while sharp

A story proof has a fixed shape: name a thing being counted, count it one way, count it a second way, conclude the two counts are equal. Write the sentence "Both sides count the number of ways to …" before you write anything else. If you can't finish that sentence, you don't have the story yet.

D1

Give a story proof that Σk=0n C(n, k) = 2n.

Solution

Both sides count the number of subsets of a set of n people.

Right side: decide independently for each person whether they are in or out — 2 choices each, 2n in total, by the multiplication rule.

Left side: sort the subsets by size. There are C(n, k) of size k, and every subset has exactly one size, so summing over k = 0, …, n counts each subset once.

Both count the same collection, so they are equal. ∎

D2

Give a story proof that for j ≤ k ≤ n,

C(n, k) · C(k, j) = C(n, j) · C(n − j, k − j).

Solution

Both sides count the number of ways to choose, from n people, a committee of size k together with a subcommittee of size j drawn from that committee.

Left side: pick the committee first (C(n, k)), then the subcommittee from within it (C(k, j)).

Right side: pick the subcommittee first, straight from all n people (C(n, j)) — this is legitimate because every subcommittee member is a committee member. Then fill the remaining k − j committee seats from the n − j people not yet chosen.

Same objects counted two ways. ∎ Sanity check with n = 5, k = 3, j = 2: 10 · 3 = 30 and 10 · 3 = 30.

D3

Show that Σk=0n C(n, k)2 = C(2n, n). Do it twice: once as a story proof from scratch, and once as a one-line consequence of Vandermonde's identity.

Solution

Story. Both sides count committees of size n chosen from n men and n women. Right side: choose n from 2n people. Left side: split by the number of men, say k; then there are C(n, k) ways to pick the men and C(n, n − k) ways to pick the women, and C(n, n − k) = C(n, k) by the complement identity. Summing over k gives the left side.

From Vandermonde. Set m = n and take the committee size to be n in C(m + n, k) = Σj C(m, j) C(n, k − j), then apply C(n, n − j) = C(n, j). ∎

Check at n = 2: 1 + 4 + 1 = 6 = C(4, 2).

D4

Give a story proof that Σk=1n k · C(n, k) = n · 2n−1.

Solution

Both sides count pairs consisting of a non-empty committee (of any size) drawn from n people, together with a captain chosen from that committee.

Left side: fix the size k, choose the committee (C(n, k)), then choose the captain from among its k members. Sum over k.

Right side: choose the captain first — any of the n people — then decide independently for each of the remaining n − 1 people whether they join, giving 2n−1. ∎

Check at n = 3: 3 + 6 + 3 = 12 = 3 · 4. Note how the same "choose the special person first" move powers both this and the team-captain identity.

D5 · stretch

Prove that Σj=kn C(j, k) = C(n + 1, k + 1).

Hint: choose k + 1 numbers from {1, 2, …, n + 1} and condition on the largest one.

Solution

Both sides count the (k+1)-element subsets of {1, …, n + 1}.

Right side: directly, C(n + 1, k + 1).

Left side: every such subset has a unique largest element. If the largest element is j + 1, the remaining k elements come from {1, …, j}, which can be done in C(j, k) ways. As j + 1 ranges over the possible maxima, j ranges from k to n. Summing gives the left side, and each subset is counted exactly once because its maximum is unique. ∎

Check with k = 1, n = 3: 1 + 2 + 3 = 6 = C(4, 2). The move to keep — "partition by the largest element" — reappears constantly in later probability arguments.

E

Axioms, properties, interpretation

≈30 min · short proofs plus arithmetic

In E1, use only the three axioms and results you have already proved from them. Naming which axiom you are invoking at each step is the whole skill being assessed.

E1

Prove each from the axioms of probability.

  1. P(Ac) = 1 − P(A)
  2. If A ⊆ B, then P(B ∩ Ac) = P(B) − P(A)
  3. P(A ∪ B) ≤ P(A) + P(B)
Solution
  1. A and Ac are disjoint with union S, so by countable additivity and P(S) = 1: 1 = P(A) + P(Ac).
  2. Write B = (B ∩ A) ∪ (B ∩ Ac), a disjoint union, so P(B) = P(B ∩ A) + P(B ∩ Ac). Since A ⊆ B we have B ∩ A = A, giving the result. Because probabilities are non-negative, this also proves monotonicity: P(A) ≤ P(B).
  3. P(A ∪ B) = P(A) + P(B) − P(A ∩ B) and P(A ∩ B) ≥ 0. This is Boole's inequality, or the union bound — you will use it constantly.
E2

Suppose P(A) = 0.4, P(B) = 0.5, P(A ∩ B) = 0.2. Find:

  1. P(A ∪ B)
  2. P(Ac ∩ Bc)
  3. P(A ∩ Bc)
  4. P(Ac ∪ B)
  5. the probability that exactly one of A, B occurs
Solution
  1. 0.4 + 0.5 − 0.2 = 0.7
  2. P((A ∪ B)c) = 1 − 0.7 = 0.3
  3. P(A) − P(A ∩ B) = 0.2
  4. P((A ∩ Bc)c) = 1 − 0.2 = 0.8
  5. P(A) + P(B) − 2P(A ∩ B) = 0.5

Sketch the four-region Venn diagram once and fill in 0.2 / 0.2 / 0.3 / 0.3. Every part above is then a matter of reading off regions, which is much harder to get wrong than manipulating formulas.

E3
  1. An event has probability 0.2. State the odds on it and the odds against it.
  2. The odds against an event are 3 to 2. What is its probability?
  3. A classmate says "odds of 3 to 1 means the probability is 1/3." Correct them.
Solution
  1. Odds on = 0.2/0.8 = 1/4, i.e. 1 to 4. Odds against = 4, i.e. 4 to 1.
  2. Odds against 3 to 2 means odds on o = 2/3, so p = o/(1 + o) = (2/3)/(5/3) = 2/5 = 0.4.
  3. Odds on 3 to 1 gives p = 3/(1 + 3) = 3/4. They have converted odds as though the second number were the total; odds compare the event against its complement, whereas probability compares it against everything.
E4

A forecast gives tomorrow a rain probability of 0.25. Two students respond:

  1. "Then over the next 4 days it must rain exactly once."
  2. "It only rained 20 times in the last 100 comparable days, so it's due — it should rain more than 25 times in the next 100."

Explain what is wrong with each, in terms of the frequentist interpretation.

Solution
  1. The frequentist reading is about the limiting proportion over many repetitions, not a guarantee within any block. Four days could easily give zero or three rainy days.
  2. The gambler's fallacy. A shortfall is not repaid — the next 100 days have no memory of the last 100. The long-run proportion converges because the early deviation is diluted by an ever-growing number of trials, not because it is corrected.

Worth a written sentence rather than a mental note: this distinction is a recurring short-answer question.

F

Inclusion–exclusion and Bonferroni bounds

≈40 min · hardest set

Inclusion–exclusion is bookkeeping: add the singles, subtract the pairs, add the triples, alternating. Bonferroni bounds are what you fall back on when the higher terms are impossible to compute.

F1

Of 200 surveyed students: 120 take a CITS unit, 90 take a STAT unit, 70 take an ELEC unit; 50 take both CITS and STAT, 30 both CITS and ELEC, 25 both STAT and ELEC; and 15 take all three. One student is chosen at random.

  1. Find the probability they take at least one of the three.
  2. Find the probability they take none.
  3. Find the probability they take exactly one.
  4. Find the probability they take exactly two.
Solution
  1. (120 + 90 + 70 − 50 − 30 − 25 + 15)/200 = 190/200 = 0.95
  2. 1 − 0.95 = 0.05
  3. Counting exactly one: S1 − 2S2 + 3S3 = 280 − 210 + 45 = 115, so 0.575.
  4. S2 − 3S3 = 105 − 45 = 60, so 0.30.

Check: 115 + 60 + 15 = 190, matching (a). Always run this check — it catches sign errors instantly.

F2

Play de Montmort's matching game with n = 4 cards.

  1. Compute the exact probability of winning using inclusion–exclusion.
  2. Verify it by counting the permutations of 4 cards with no match at all.
  3. Compare with the limiting value 1 − 1/e. Is n = 4 already close?
Solution
  1. 1 − 1/2! + 1/3! − 1/4! = 1 − 0.5 + 0.1667 − 0.04167 = 0.625 = 5/8.
  2. There are 4! = 24 permutations, of which 9 have no fixed point (these are the derangements). So P(win) = 1 − 9/24 = 15/24 = 5/8. ✓
  3. 1 − 1/e ≈ 0.6321 against 0.625 — already within about 0.007. The alternating series converges very fast because the terms are 1/k!.

The striking part of this result is that the answer barely depends on n: a deck of 4 and a deck of 52 give essentially the same winning probability.

F3

A statistician reports 20 confidence intervals. Each is individually correct with probability 0.99. Let Ai be the event that the ith one is correct.

  1. Using De Morgan and the union bound, show P(∩i Ai) ≥ 1 − Σi P(Aic).
  2. Apply it: what can you guarantee about the probability that all 20 are correct?
  3. What does the first Bonferroni bound, P(∪i Ai) ≤ Σi P(Ai), tell you here?
  4. How many intervals could the statistician report and still guarantee at least 90% confidence that all are correct?
Solution
  1. P(∩Ai) = 1 − P((∩Ai)c) = 1 − P(∪Aic) ≥ 1 − Σ P(Aic), the last step by the union bound extended to n events.
  2. 1 − 20(0.01) = 0.80. Note what the bound does not require: nothing at all about dependence between the intervals.
  3. Nothing useful. Σ P(Ai) = 19.8, and every probability is already at most 1, so the bound is vacuous. Bounds can be valid and still worthless.
  4. Need 1 − 0.01n ≥ 0.9, so n ≤ 10.

This is the multiple-comparisons problem in miniature, and the reason Bonferroni corrections exist. The guarantee erodes linearly in the number of statements you make.

F4

Three events satisfy P(Ai) = 0.4 for each i, P(Ai ∩ Aj) = 0.1 for each pair, and P(A1 ∩ A2 ∩ A3) = 0.05.

  1. Compute P(A1 ∪ A2 ∪ A3) exactly.
  2. Compute the successive Bonferroni bounds P1, then P1 − P2, then P1 − P2 + P3, and check each has the direction the theorem claims.
  3. Why does the third bound land exactly on the true value here?
Solution
  1. 1.2 − 0.3 + 0.05 = 0.95
  2. P1 = 1.2 ≥ 0.95 ✓ (an upper bound, though a useless one, since it exceeds 1). P1 − P2 = 0.9 ≤ 0.95 ✓ (a lower bound). P1 − P2 + P3 = 0.95 ≥ 0.95 ✓ (an upper bound, met with equality).
  3. With n = 3 there are no further terms — the alternating series terminates, so the third partial sum is inclusion–exclusion. Bonferroni bounds are just truncations of the exact formula, which is why they alternate between over- and under-shooting.
