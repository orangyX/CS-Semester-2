Rules

Given $V_{IL}$: $V_{OH}=\min V_{OUT}$ on $[0,V_{IL}]$. Given $V_{IH}$: $V_{OL}=\max V_{OUT}$ on $[V_{IH},5]$. Given $V_{OH}$: $V_{IL}$ is the largest input with $V_{OUT}\ge V_{OH}$ all the way from 0. Given $V_{OL}$: $V_{IH}$ is the smallest input with $V_{OUT}\le V_{OL}$ from there to 5 V.

Scheme A

On $[0,1.0]$ the curve falls from 4.8 to $V_{OUT}(1.0)=4.8-3(0.2)=4.2$, so $V_{OH}=4.2$. On $[2.6,5]$ the maximum is $V_{OUT}(2.6)=1.2-2(0.2)=0.8$, so $V_{OL}=0.8$. $NM_L=1.0-0.8=0.2$, $NM_H=4.2-2.6=1.6$.

Scheme B

On $[0,1.4]$ the minimum is the dip, $V_{OUT}(1.2)=3.6$, so $V_{OH}=3.6$ (not $V_{OUT}(1.4)=4.0$). The output first reaches 0.4 V at 2.8 V and stays there, so $V_{IH}=2.8$. $NM_L=1.4-0.4=1.0$, $NM_H=3.6-2.8=0.8$.

Scheme C

$V_{IH}=2.0$ forces $V_{OL}\ge V_{OUT}(2.0)=4.4-4(0.4)=2.8$. $V_{OH}=4.2$ forces $V_{IL}\le 1.0$. Then $NM_L\le 1.0-2.8=-1.8\lt 0$: X.

B1designcf. Prac 2 Q1(a)

A 3D-printer safety controller has inputs $H$, $L$, $F$, $M$ and outputs $S$ (stop) and $W$ (warning lamp). $H=1$: heater on. $L=1$: lid closed. $F=1$: filament present. $M=1$: motor running.

  • $S=1$ if and only if the heater is on and the lid is open, or the motor is running and at least one of these holds: the filament is absent, the lid is open, or the heater is off.
  • $W=1$ if and only if the heater is on, the lid is open, and either the filament is absent or the motor is not running.

Write $S$ and $W$ in sum-of-products form.

$$S = H\overline{L} + M(\overline{F}+\overline{L}+\overline{H}) = H\overline{L} + M\overline{F} + M\overline{L} + M\overline{H}$$

$$W = H\overline{L}(\overline{F}+\overline{M}) = H\overline{L}\,\overline{F} + H\overline{L}\,\overline{M}$$

Both are distributive-law expansions. $M\overline{L}$ is the consensus of $H\overline{L}$ and $M\overline{H}$, so $S = H\overline{L} + M\overline{F} + M\overline{H}$ is also correct and minimal. Checked against the spec on all 16 rows: $S=1$ on 9 rows, $W=1$ on 3.

B2designcf. Prac 2 Q1(b)

Implement the four-term $S$ and the two-term $W$ from B1 as two separate circuits with inputs $H, L, F, M$, using only inverters, 2-input AND gates and 2-input OR gates. Build each product term with its own gates (no sharing between terms). How many of each gate type does each circuit use?

S

Inverters for $\overline{H},\overline{L},\overline{F}$: 3 NOT. One AND per two-literal term: 4 AND. Four terms need $4-1$ two-input ORs: 3 OR.

W

Inverters for $\overline{L},\overline{F},\overline{M}$: 3 NOT. Each three-literal term needs two cascaded 2-input ANDs: 4 AND. Two terms: 1 OR.

General count: a $k$-literal product costs $k-1$ two-input ANDs; an $n$-term sum costs $n-1$ two-input ORs.

Part C · Boolean algebra simplification

3 questions · ~25 min

Practical 2 Q3–Q4 types. Apply De Morgan first, then distribute, then absorb. C3 relies on spotting a consensus term.

C1computecf. Prac 2 Q3(a)–(b)

Find a minimal sum-of-products expression for each.

  1. $\overline{a\overline{b} + c + \overline{a}}$
  2. $(a+b)c + \overline{b}a + c(\overline{a}+b)$
(a)

De Morgan on the sum, then on $a\overline{b}$, then distribute:

$$\overline{a\overline{b}}\cdot\overline{c}\cdot a = (\overline{a}+b)\,\overline{c}\,a = a\overline{a}\,\overline{c} + ab\overline{c} = ab\overline{c}$$

($a\overline{a}=0$, complement.) Check: true only for $abc=110$ ✓.

(b)

$$ac + bc + a\overline{b} + \overline{a}c + bc = (a+\overline{a})c + bc + a\overline{b} = c + bc + a\overline{b} = c + a\overline{b}$$

Distributive, idempotence ($bc+bc=bc$), complement, identity, absorption ($c+bc=c$). Check: 1-rows are $abc \in \{001,011,100,101,111\}$ ✓.

C2computecf. Prac 2 Q3(c)–(d)

Find a minimal sum-of-products expression for each.

  1. $\overline{a}\;\overline{bc}\,\big(c + \overline{a}(b+c)\big)$
  2. $b\big(a + c(\overline{d} + ef)\big)$

In (a), shrink the bracket first: $c + \overline{a}c$ absorbs.

(a)

Bracket: $c + \overline{a}b + \overline{a}c = c + \overline{a}b$ (absorption). De Morgan: $\overline{bc}=\overline{b}+\overline{c}$.

$$\overline{a}(\overline{b}+\overline{c})(c+\overline{a}b) = \overline{a}\big(\overline{b}c + \overline{a}\,\overline{b}b + \overline{c}c + \overline{a}b\overline{c}\big) = \overline{a}\,\overline{b}c + \overline{a}b\overline{c}$$

$\overline{b}b = \overline{c}c = 0$ (complement); $\overline{a}\,\overline{a}=\overline{a}$ (idempotence). The two terms differ in two variables, so nothing combines. Check: 1-rows $abc \in \{001, 010\}$ ✓.

(b)

Distribute twice:

$$ab + bc(\overline{d}+ef) = ab + bc\overline{d} + bcef$$

No term contains another, so this is minimal (8 literals). Verified on all 64 rows ✓.

C3computecf. Prac 2 Q4

Simplify to the stated number of literals, in sum-of-products form.

  1. $X = \overline{\overline{A+B} + C\,\overline{\overline{A}B}}$   to 4 literals
  2. $Y = \overline{\overline{A\overline{B}}\,(A+C)} + B$   to 3 literals

Both expand to three terms where one is redundant: $XY + \overline{X}Z + YZ = XY + \overline{X}Z$ (consensus).

(a)

De Morgan on the outer bar, then on $\overline{C\,\overline{\overline{A}B}}$:

$$X = (A+B)\cdot\overline{C\,\overline{\overline{A}B}} = (A+B)(\overline{C} + \overline{A}B)$$

$$= A\overline{C} + A\overline{A}B + B\overline{C} + \overline{A}B = A\overline{C} + B\overline{C} + \overline{A}B$$

$B\overline{C}$ is the consensus of $A\overline{C}$ and $\overline{A}B$:

$$X = A\overline{C} + \overline{A}B \quad (4\text{ literals})$$

Check: 1-rows $ABC \in \{010,011,100,110\}$ ✓.

(b)

Inside: $\overline{A\overline{B}} = \overline{A}+B$, so $(\overline{A}+B)(A+C) = \overline{A}C + AB + BC = \overline{A}C + AB$ (consensus drops $BC$).

Complement it with De Morgan:

$$\overline{\overline{A}C + AB} = (A+\overline{C})(\overline{A}+\overline{B}) = A\overline{B} + \overline{A}\,\overline{C} + \overline{B}\,\overline{C} = A\overline{B} + \overline{A}\,\overline{C}$$

Add $B$: $B + A\overline{B} = B + A$, then $A + \overline{A}\,\overline{C} = A + \overline{C}$.

$$Y = A + B + \overline{C} \quad (3\text{ literals})$$

Check: $Y=0$ only at $ABC=001$ ✓.
